Guía para Publicar en GitHub Pages y Hosting de Paga

Modo Gratuito (GitHub Pages): Cualquier cambio que realices aquí se almacena inmediatamente en tu navegador. Para publicar los cambios de forma definitiva para tu clienta, pulsa el botón superior "Descargar JSON para GitHub", reemplaza el archivo data/cms_store.json en tu repositorio local y haz un git commit & push.

Modo Hosting de Paga: Si ejecutas el microservidor incluido (python3 server/portable_cms_server.py o lo subes a cualquier hosting con Node o Python), los cambios se guardan directamente en el disco del servidor sin necesidad de pasos adicionales.
